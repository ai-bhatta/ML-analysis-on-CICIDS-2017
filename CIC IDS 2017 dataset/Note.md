## 📂 Dataset Information

The dataset used in this project is the **CIC IDS 2017** dataset, which contains realistic network traffic for intrusion detection research.

You can download the dataset from the official website using the link below:

🔗 [CIC IDS 2017 Dataset – UNB Canadian Institute for Cybersecurity]
(https://www.unb.ca/cic/datasets/ids-2017.html)
